# 行为准则 · Code of Conduct

## 我们的承诺

为建设开放、友好的益米社区，贡献者与维护者承诺：无论年龄、体型、残障、族裔、性别认同与表达、经验水平、国籍、外貌、种族、宗教或性取向，人人免受骚扰。

## 鼓励的行为

- 使用欢迎与包容的语言  
- 尊重不同观点与经验  
- 优雅地接受建设性批评  
- 关注对社区最有利的事  
- 对其他成员表示同理  

## 不可接受的行为

- 性暗示语言/图像，不受欢迎的性关注  
- 引战、侮辱/贬损评论、人身或政治攻击  
- 公开或私下骚扰  
- 未经许可发布他人隐私信息  
- 故意提交侵权内容或恶意代码  
- 冒充小米/米家或其他公司官方身份  

## 执行

可通过项目 Issues（标题加 `[conduct]`）或维护者邮箱报告。维护者有权删除、编辑、拒绝不符合本准则的评论、提交、代码与 Issue，并暂时或永久封禁贡献者。

## 归属

改编自 [Contributor Covenant](https://www.contributor-covenant.org) 2.1 版精神，简化适用于本仓库。
