## 1. 要证明的单一旅程

```text
家长读取空白 OID
  → 命名“水杯”
  → 录一句真人语音或生成基础 TTS
  → 预听并确认
  → 编译 Snapshot
  → USB stage / verify / activate
  → 拔线、断网、重启
  → 儿童点水杯贴，设备本地一点即播
```

这个旅程必须在目标形态笔上成立，不依赖电脑、手机或网络参与播放。

## 2. 为什么选择这一切片

| 依据 | 结论 |
|---|---|
| `SRC-OID-001` 官方方案描述 | OID、主控、本地存储和扬声器构成成熟基础点读链 |
| `SRC-OID-002/003` 官方方案族 | 无线、App 和云是可选扩展，不需要占据本地点读热路径 |
| PIYO/JoJo 既有 `S/R/V` 调研 | 预装内容、少按键、内容管理和点读贴值得实物复核，不直接照抄内部实现 |
| `theory.md` | 益米差异化是开放 Pack、家庭 DIY 和亲情内容 |
| `hardware-gen1-p0.md` | 真实 OID、离线、P95 `<200ms`、完整目标形态和可靠性是验收门 |

结论：先证明“家庭创建一张贴并离线即时播放”，比先做云问答、拍照成书或社区 Hub 更能验证产品核心。

## 4. 24码构成

| 槽位 | 类别 | 覆盖 |
|---|---|---|
| `001–006` | 开箱与基础认知 | 唯一映射、短句、音效、WAV/MP3覆盖 |
| `007–012` | 玩具感播放策略 | `random_one`、权重、`queue`、`replace`、停止/打断 |
| `013–018` | 家庭 DIY | 真人录音、基础 TTS、多句贴、生活物品和睡前场景 |
| `019–024` | 运行时与恢复 | 快速交替、冷却、相邻边界、重启和快照持久化 |

每个槽位的完整字段和 oracle 以 `codes.json` 为真源，其中 `cooldownMs` 是执行值而不是
自然语言备注。Snapshot design 由 `npm run generate:golden-24-projection` 生成，CI/本地用
`npm run validate:golden-24-projection` 做逐字节检查；Family Alpha 子集同步核对 kind、
策略、冷却、clip 数和来源类型。24 个槽位全部先使用逻辑 OID；目标码工具锁定后，才写入
物理码映射。

## 6. 成熟产品实物基准协议

`REF1–REF4` 到货或借到后，按精确 SKU 分别记录：

1. 包装条码、铭牌、生产批次、固件/App版本和配套码书；
2. 长宽直径、重量、按键数/键义、灯位、充电口和出声孔；
3. 冷启动、首次点读、重复点、快速切换、未绑定、低电、存储/升级失败反馈；
4. 断网、拔线和关闭无线后的核心点读；
5. P50/P95/P99 首音、最大声压、混合工况续航；
6. 内容安装、版本更新和回滚的可观察行为；
7. 非破坏测试结束后，再对牺牲样品做分层拆解。

所有数据绑定到具体 SKU/revision。不同批次出现差异时建立新行，不用“功能一样”合并。

样品数据使用 `EVT-0 Evidence Intake v1`：到货前保持 `PENDING + null`，供应商文件标 `VENDOR_DOCUMENT`，铭牌/界面标 `OBSERVED`，仪器结果标 `MEASURED`。主板只有在两套身份一致、强制测试全部结清且 intake workflow blocker 清空后才进入 `ACCEPTED_BOARD_TARGET`；这些到货工作流原因与最终 `RG-*` 发布 gate ID 分域。

## 7. 当前保持未定的字段

- 真实物理码数值；
- OID 码生成器和印刷 profile；
- 主板/光头/固件 revision；
- 目标采样率、MP3 profile、文件名/目录长度限制；
- BLE/WiFi 和移动端传输范围；
- OpenVela或供应商 RTOS 的最终选择；
- 最终颜色、灯语节奏、按键位置和工业设计。

这些字段都有明确证据门，当前文件不使用推测值填空。

## 8. 退出门

黄金产品切片进入实物联调前必须满足：

1. `codes.json` 通过结构检查且恰好 24 个唯一逻辑 OID；
2. `BOARD_TARGET` 和 OID 工具链拥有精确版本证据；
3. 24 个物理码全部由封存工具生成并通过重复/冲突检查；
4. 目标音频能力表已经逐项播放验证；
5. Snapshot v1 的 stage、verify、activate、rollback 已在模拟器通过；
6. 两个印刷批次和两个光头进入同一验收矩阵。
