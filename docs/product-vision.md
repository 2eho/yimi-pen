# 产品定位：益米 · 开源「万物可点」

> 完整理论与已拍板决策见 **[theory.md](./theory.md)**（冻结版）。本文为摘要。

## 品牌

| | |
|--|--|
| 中文名 | **益米点读笔** |
| 英文名 | **Yimi Pen** |
| 含义 | 有益启蒙 + 社区「米」生态友好（**非小米官方**） |
| 形态 | 开放引擎 + 社区/DIY 内容 + AI 生成辅助 + 可选 IoT 桥接 |

## 真正杀手锏（不是兼容机）

大厂靠**封闭书库**锁用户。益米不走「偷资源 / 兼容别人的商业包」，而走：

> **开放生态 + 实体/图书双 DIY + IoT 互联 + AI 生成**

社区规则第一条（硬约束）：

**禁止传播任何受版权保护的商业点读包。**

## 对标

| | 学段教辅笔 | 封闭 IP 发声书 | **益米** |
|--|------------|----------------|----------|
| 内容来源 | 教材墙 | 官方套装 | **公版 / 自制 / DIY 生成** |
| 点什么 | 指定课本 | 指定绘本 | **贴纸物体 + 自制页 + 社区包** |
| 护城河 | 题库/评测 | IP 授权 | **创作工具链 + 开放格式 + 社区** |

体验可参考小鸡球球/JoJo 的「好玩」，但供给模型完全不同：**用户与社区生产内容**。

## 双 DIY 主路径

### 路径 1：实体万物 DIY（贴纸）

```
空白 OID 贴纸 → 贴到香蕉/水杯/玩具
     → 笔一点
     → App：拍照识别 / 用户命名
     → AI：短故事、拟声、角色台词
     → 生成 clip，绑定该 OID
```

场景：「给香蕉贴一张益米贴，点一下听香蕉冒险故事。」

### 路径 2：图书 DIY（拍照成书）

```
拍实物/画作 → AI 卡通化 → 排版成页
     → TTS/故事旁白 → 导出 book.json 主题包
     → 家用打印 / 打印店 → 实体小绘本
     → 笔按页点读
```

场景：「拍家里的猫，生成绘本页，打印出来和娃一起点。」

两条路径共用：**同一套 Hotspot / Clip / Pack 格式**（见 domain + pack-spec）。

## 方案取舍（与外部建议对齐）

| 方案 | 含义 | 益米态度 |
|------|------|----------|
| A 极致普惠 | 公版+自制+拍照生成贴纸/语音 | **主航道，优先做** |
| B 硬件降维 | 笔当智能中控 + 大模型童话 | **可选增值，不做唯一卖点** |
| 兼容大厂商业包 | 解密/盗刷别人点读书 | **禁止，法务与品牌红线** |

IoT（关灯、场景联动）可以有，但定位是 **「点读生活的开关」**，不是替代米家官方中控。

## 体验原则

1. **先本地、后云**：生成结果缓存成包，点读不依赖每次联网  
2. **儿童安全**：故事过滤、无惊吓默认档、家长确认后写入笔  
3. **创作有成就感**：贴纸墙、家庭绘本架、一键分享（仅限合规包）  
4. **开放可插拔**：换模型提供商、换 TTS、换打印模板  
5. **亲情音色**：录入爸妈声音后，打字/AI 文案用熟悉人声朗读（非门禁声纹）  

## 主动不做

- 应试搜题 / 口语考级  
- 冒充小米/米家官方  
- 任何商业点读包破解、镜像、私服  

## 成功指标

- 家庭 DIY 包创建数、贴纸绑定次数  
- 公版/自制 pack 安装量（合法）  
- 生成内容家长确认率 / 违规拦截率  
- （次要）IoT 场景触发次数
