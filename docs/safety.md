# 益米 · 儿童与内容安全定稿

> 状态：**理论定稿 v0.1**（专题 1/3）  
> 上级文档：[theory.md](./theory.md)  
> 范围：人身安全、内容安全、亲情音色伦理、数据最小化。  
> 不范围：具体芯片认证报告、法务意见书（须专业人士）。

---

## 0. 一句话

**益米默认假设使用者是幼儿；任何「好玩」不得以听力、误食、误服信息、惊吓或滥用亲人声音为代价。不确定时，选择更保守的一档。**

---

## 1. 安全原则（D-S 系列，与 theory 对齐）

| ID | 原则 |
|----|------|
| **S1 儿童优先** | 冲突时，儿童身心安全 > 功能完整 > 增长指标 |
| **S2 家长确认门** | AI/拍照/云合成写入点读前，须监护人可理解的确认（可批量，不可静默） |
| **S3 失败可感知** | 识别失败、合成失败、无绑定时，禁止长时间死寂；用短提示音/灯语/语音 |
| **S4 最小采集** | 只采点读与创作所需；默认本地；上云二次同意 |
| **S5 可删可停** | 绑定、样本、音色、生成缓存均可删除；停用优先于「永久纪念」默认 |
| **S6 分类高风险** | 药、清洁剂、锐器、烟酒等物体类别：拦截或强警告，不得当普通水果故事 |
| **S7 听力保护** | 童锁最大音量；出厂默认中低音量 |
| **S8 材料诚实** | 贴纸分档；不鼓励食品入口面粘贴；食品接触须明示等级 |

## 2. 人身与硬件相关安全

### 2.1 听力

| 要求 | 说明 |
|------|------|
| 最大音量 | 产品定义童锁上限（工程标定 dB(A)，量产前实测） |
| 默认音量 | 出厂 ≤ 中档；首次开机提示可调 |
| 突然响度 | 禁止广告式突然最大音；故事/音效做响度归一 |
| 长时间 | 连续播放可提示休息（可关，默认开，文案非恐吓） |

### 2.2 误食与结构

| 要求 | 说明 |
|------|------|
| 小零件 | 贴纸边角、笔帽等符合目标年龄段玩具规范思路；包装警示 |
| 笔形 | 避免过小可吞部件；充电口防异物（工程项） |
| 线材 | 若有线充，缠绕风险按玩具常规处理 |

### 2.3 材料与「贴在香蕉上」

**理论立场（补 theory 曾漏项）：**

1. **官方贴纸默认定位 =「物品表面」**（杯、书、积木、家具），**不默认 = 可食果皮长期粘贴。**  
2. 营销与教程中的「香蕉」是**万物可点的隐喻与 Demo**；量产说明须写清：  
   - 可临时贴于未破损果皮外作演示，用后取下；  
   - 或使用**食品接触级/可剥离**专用贴（若提供 SKU）；  
   - **禁止**暗示「胶水可入口」。  
3. 背胶、油墨、基材须走玩具/文具材料合规路径；食品接触 SKU 单独认证与包装标识。  
4. DIY 用户自备贴纸：文档提示材料自负，益米不保证第三方贴。

### 2.4 电池与电气

- 量产须满足适用的电池与充电安全要求（地区法规另册）。  
- 开源阶段：模拟器无电气风险；参考硬件文档须列「未认证、勿商用」.

### 2.5 使用环境

| 场景 | 态度 |
|------|------|
| 浴室/浴缸 | 非防水笔默认禁止；防水版另标 |
| 户外暴晒/雨 | 识别率下降 → 走 S3 失败反馈 |
| 开车 | 不鼓励驾驶中操作 |

## 3. 识别与「错误知识」安全

### 3.1 拍照 / 自动标签

流水线必须是：

```
拍照 → 候选标签（可多选）→ 风险分类
     → 若高风险：拦截或强提示
     → 家长确认名称与文案
     → 才写入 DIY 绑定
```

**禁止：** 拍照后静默生成故事并直接可点。

### 3.2 高风险物体类别（示例，可扩展词表）

| 类别 | 策略 |
|------|------|
| 药品、药盒、注射器 | **默认拦截**绑定故事；仅允许家长手写「这是药，不能吃」类警示模板 |
| 清洁剂、打火机、刀具、烟酒 | **强警告** + 确认；推荐警示话术非娱乐化 |
| 未知低置信 | 不自动命名；请家长手输 |
| 普通食物/玩具/日用 | 正常 DIY，仍需确认文案 |

### 3.3 AI 故事与知识

| 风险 | 策略 |
|------|------|
| 惊吓、恐怖、死亡细节 | 默认年龄档过滤；睡前档更严 |
| 错误知识（「XX 能当糖吃」） | 高风险类禁用幽默误导；通用类免责 + 家长确认 |
| 歧视/脏话/性暗示 | 硬拦截 |
| 模仿商业 IP | 过滤器 + 社区审核；用户原创责任 |

### 3.4 年龄档（内容）

| 档 | 建议 |
|----|------|
| 0–2 | 极短句、强音效克制、无复杂情节 |
| 2–4 | 默认档：温和、重复、拟人可爱 |
| 4–6 | 可稍长故事；仍避免恐怖 |
| 家长自定义 | 可放宽，须显式切换并记入设置 |

## 4. 点读交互安全

### 4.1 失败可感知（S3）

| 事件 | 儿童侧反馈（建议） |
|------|-------------------|
| OID 未绑定 | 短音 +「还没有故事哦」（可关语音只留音） |
| 识别失败 | 与上类似，不假装成功 |
| 音频缺失 | 提示音；日志给家长 |
| 冷却中 | 可静默或极轻音，防刷屏刺耳 |

### 4.2 连点与音量

- cooldown 防刷屏。  
- 快速连点不得叠加多路音频到破音（引擎 replace 默认）。  

### 4.3 睡前模式（建议产品态）

- 降默认音量、减随机尖叫音效、故事结束停止。  
- 可选定时停止。

## 5. 亲情音色伦理与安全

（与 [voice-profile.md](./voice-profile.md) 一致，上升为安全约束）

| 规则 | 说明 |
|------|------|
| 同意 | 录入前明文：用途=家庭朗读，非解锁 |
| 禁止默认云 | 未同意不上传送样 |
| 可删 | 样本、模型句柄、缓存语音 |
| 防滥用 | 合成前过内容安全；童锁可禁「自由打字直出」 |
| 敏感人生 | 不做「已故亲人默认音色」运营话术；提供删除/归档 |
| 公开 Pack | 默认禁止附带他人 VoiceProfile 样本 |
| 儿童声 | 录孩子声音须监护人同意，且慎用公开分享 |

**不做：** 声纹支付、陌生人识别、未授权公众人物模仿。

## 6. 数据与隐私

| 数据 | 默认 |
|------|------|
| DIY 绑定文案 | 本地 |
| 录音样本 | 本地；云复刻另授权 |
| 照片（识物） | 处理完可删；默认不建云相册 |
| 点读历史 | 可选、可关、可清 |
| 崩溃日志 | 脱敏；无音频原文默认 |

家庭多成员：权限模型见未来 `family-space`；安全底线是 **能删、能导出、能退出云**。

| 规则 | 说明 |
|------|------|
| 商业点读包盗传 | 禁止（theory 第一条） |

## 9. 明确不承诺

- 无法 100% 杜绝 AI 不当输出 → 靠确认门 + 过滤 + 举报。  
- 无法保证第三方贴纸无毒 → 官方 SKU 与第三方分离责任。  
- 开源固件被改装后的音量/内容 → 官方发行版负责，改装自负。

## 11. 开放问题

- 具体 dB 数值与认证实验室路径  
- 大陆生成式 AI 标识/备案若接云时的产品形态  
- 幼儿园场景是否单独安全档（多孩无「家庭确认人」）
