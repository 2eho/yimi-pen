## 1. 采购规则

1. 每个目标件必须记录品牌、完整料号、硬件 revision、固件/SDK revision、购买链接、卖家、批次和到货照片。
2. 样机与批量使用同一个 `BOM-REV-A`。卖家写“随机版本”“同规格替代”或只给功能描述的商品不进入目标 BOM。
3. 关键件单买 2-3 个：一件装机、一件封存基准，破坏性测试件另计。这是工程冗余，不是批量备货。
4. 先锁近期一体主板/OID 套件、扬声器、电芯和外壳机械包络；一体板失格后才进入同版自研主板，不先画大转接板凑合。
5. 小鸡球球、宝贝 JoJo 和讯飞是对标样品。它们的拆机件不直接装入益米，除非该件有可追溯料号、独立资料和后续同型号供货。
6. 单件阶段也做来料检查、版本封存和验收记录；以后批量采购只扩大数量，不重新猜规格。

搜索结果优先落到 **可单买的近期一体主板 + 同版 OID 光头套件**，不能只买一支封闭成品笔，也不能只得到一张没有协议/板号的公板照片。单独 OID 模组作为自研板分支候选。

### 3.2 下单前固定问法


## 6. 到货检验

每批件建立同一份记录：

```text
item_id / MPN / revision / seller / order_id / lot_or_date_code
ordered_qty / received_qty / photo_paths / document_hashes
dimensions / electrical_checks / functional_checks
accepted | quarantined | rejected
reason / inspector / date
```

关键检查顺序：

1. 未上电先核对标签、外观、极性、尺寸和对地阻抗；
2. 一体主板/OID 套件使用限流电源和原始固件/示例，24 码逐码记录原始事件；
3. microSD 做全盘写读；电芯做开路电压、内阻、容量和 NTC 检查；
4. 扬声器三只用同一夹具比较声压、异响和频响；
5. 任何版本不符、返修痕迹、资料缺失或性能离群件进入隔离盒，不装目标机。

### 6.1 OID 光学/印刷对照页

使用目标码生成工具和目标印刷流程制作两个独立印刷批次；每批均包含以下对照：

| 页型 | 目的 |
|------|------|
| 供应方标准码卡 | 建立模组与解码基准 |
| 白底 + 目标点码层 | 分离点码、纸张和光头问题 |
| 浅色 CMYK 插画 + 同一 OID | 验证常规图文叠印 |
| 深色 CMY / K-rich 插画 + 同一 OID | 验证低反射、高颜料覆盖和黑色画面风险 |
| process-black / K-only + 同一 OID | 区分普通黑墨、碳黑和专用点码墨的近红外响应 |
| 与插画相同但无 OID | 验证图文油墨不会产生有效码误触发 |
| 哑膜 / 亮膜各一页 | 验证反射、工作距和入射角风险 |

每页记录印刷设备、RIP/ICC、分色/叠印、油墨或墨粉 SKU/碳黑信息、纸张、覆膜、DPI/LPI、点径/点距、缩放、批次和日期。手机微距图只用于观察点阵和套准，最终结论来自两只目标 OID 光头跨两批印刷的原始事件与统计。

## 8. 下单顺序

1. 先下单小鸡球球、宝贝 JoJo 和一支可牺牲 OID 样品；讯飞可借用。
2. 同时筛选并单买两套同板号/revision 的近期一体主板/OID 套件，完成正反面、板号、功能、来料读码和资料门。
3. 一体主板通过就锁定其机械/电气边界、扬声器和电芯尺寸，完成 `BOM-REV-A`；失格后才启动自研板原理图/PCB。
4. 使用锁定主板制作两套目标外壳；自研分支才下目标 PCB/SMT，始终不下开发板转接版。
5. 完成一支基准机和一支可靠性机，跑完 [目标样机完成门](../hardware-gen1-p0.md#8-完成门)。
6. 通过后把同一 revision 送入 [批量 RFQ](./gen1-p0-oid-rfq.md)，只讨论数量、交付、良率、认证和经验证的改版。
