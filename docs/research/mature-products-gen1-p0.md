# Gen1 EVT-0 成熟产品对标

> 调研日期：2026-07-26
> 目的：把小鸡球球、宝贝 JoJo 与讯飞的成熟做法转成 Gen1 工程样笔的可测规格。
> 范围：公开页面、零售详情图和后续实物测量；不据此推断未公开电路，也不承诺兼容商业点读书库。

## 1. 证据标记

| 标记 | 含义 | 使用方式 |
|------|------|----------|
| `O` | 品牌官方商城、官方手册或可核验铭牌 | 可作为产品事实，仍记录具体版本 |
| `S` | 有引用链的二手资料或百科汇总 | 只作候选事实，采购后用铭牌和实测复核 |
| `R` | 零售商品标题、详情或卖家说明 | 证明市场上存在该版本，不等同于工程规格书 |
| `V` | 从公开商品图直接观察 | 只描述看得见的结构或界面，不猜内部实现 |
| `U` | 用户提供的业余视频转写或示意图 | 只形成待验证假设和测试项，不作为料号、尺寸、波长或印刷参数 |
| `E` | 益米工程目标或估算 | 进入 EVT-0 验收，不写成竞品事实 |

## 2. 三类产品各自回答什么问题

| 参照 | 产品类型 | 最值得验证的问题 | 不直接照搬 |
|------|----------|------------------|------------|
| 小鸡球球 PIYO PEN PW20 | OID 点读笔 + 内容生态 | OID、熏听、自制点读和外部音频如何共存 | 商业书库兼容、版本降级和专有点读包 |
| 宝贝 JoJo 32G WiFi 版 | IP 内容型 OID 点读笔 | 低按键负担、App 装内容、固件升级和角色化反馈 | IP 素材、会员体系和卖家宣称的内容数量 |
| 讯飞 AI 词典笔 X8 Pro | 带屏扫描词典笔 | 即时反馈、分阶段任务、语音交互和复习闭环 | 屏幕、OCR 扫描主路径和重型在线系统 |

结论：小鸡球球和宝贝 JoJo 是 Gen1 的同类体验基线；讯飞是交互质量基线，不是硬件架构基线。

## 3. 可核验观察

### 3.1 小鸡球球 PIYO PEN PW20

公开汇总页面记录了以下信息，证据级别均为 `S`，到货后必须复核：

| 项 | 公开信息 | 对 EVT-0 的含义 |
|----|----------|---------------|
| 型号与存储 | PW20，32GB | EVT-0 与目标产品使用同品牌/系列 32GB 存储，不用临时小容量介质 |
| 电源 | 650mAh 聚合物锂电池，5V/1A 输入 | EVT-0 与目标产品均以 650-800mAh、USB-C 5V/1A 为目标窗 |
| 材料 | ABS、PC、硅胶 | EVT-0 直接验证目标软硬材料分区、握持、镜头保护和跌落结果 |
| 核心模式 | 绘本点读、熏听、AI 问答、亲子微聊 | 点读与熏听共用音频链路；AI 不进入本地点读时延路径 |
| 扩展 | 点读贴、自制音频、导入外部音频 | 益米继续坚持“逻辑 OID + 家庭内容快照” |
| 内容更新 | 通过存储目录放入点读包 | EVT-0 与目标产品保留 USB 装包，点读不依赖无线账号体系 |

页面还记录了不同出厂时间的内容兼容差异。这个现象只用于提醒益米把 `硬件型号 / 固件版本 / 内容格式版本` 分开管理，不作为复现其兼容流程的需求。

### 3.2 宝贝 JoJo 32G WiFi 版

当前可用证据主要来自零售页，事实强度低于官方手册：

| 观察 | 证据 | 对 EVT-0 的含义 |
|------|------|---------------|
| 商品标题明确写有“32G WiFi 版” | `R` | 无线同步是成熟 SKU 的常见能力，但 EVT-0 与目标点读均不得依赖网络 |
| 详情图展示 32G、App 下载、在线播放、音频文件管理和固件升级 | `R/V` | 家长端最终统一管理内容与升级；EVT-0 先用目标 USB 通道完成同一闭环 |
| 详情图展示出厂儿歌、首次联网权益及大规模在线音频 | `R/V` | 本地基础内容与可选在线内容分层，不能把在线数量当离线能力 |
| 正面可见一个长形控制区、一个圆形按键和状态灯位置 | `V` | 幼儿主交互应保持少按键；具体键义等实物到货确认 |
| 商品图明确提示点读书需另购 | `R/V` | 工程样笔、码卡和内容包要分别验收，避免“有笔无可测码” |
| 详情页展示检测报告截图 | `R/V` | RFQ 要求原始报告编号、型号覆盖范围与有效期，不采信截图本身 |

零售图中的“10万+音频”、分类数量和会员权益属于营销口径，只用于研究内容导航，不进入 EVT-0 硬件验收。

### 3.3 讯飞 AI 词典笔 X8 Pro

讯飞官方商品页及详情图给出的 `O` 级信息包括：

| 项 | 官方页面信息 | 可借鉴做法 |
|----|--------------|------------|
| 输入 | 扫描查词、分阶段查询 | 操作后立即确认输入已被识别，再进入内容播放 |
| 反馈 | 3.5 英寸屏、语音与结构化结果 | 无屏 EVT-0 用短音效 + RGB 灯表达同样的状态层级 |
| 学习流程 | 自主预习、复习、背词检测、错题回顾 | 点读内容也应支持“播放、暂停、再听、完成”清晰状态 |
| 语音能力 | AI 口语陪练、语法解析等 | 语音交互可后置到家长端或联网模式，不挤占 OID 主链路 |
| 存储与连接 | 32GB、2.4/5GHz WiFi、Type-C、蓝牙耳机 | 32GB 与 Type-C 进入 EVT-0/目标 BOM；双频 WiFi 和蓝牙耳机不属于 Gen1 冻结功能 |
| 电池 | 1100mAh | 带屏设备不可直接作为无屏点读笔续航基准 |

讯飞的核心启发不是加屏，而是每一步都有确定反馈、失败原因和下一动作。

## 4. 转成益米 EVT-0 的设计决策

| 成熟做法 | Gen1 EVT-0 决策 | 验证方式 |
|----------|-------------|----------|
| 点一下立即有反应 | 识码成功先给灯/短音确认，缓存音频首音 P95 `<200ms` | 高速录像或日志同源时间戳 |
| 幼儿少按键 | 电源/播放复用键 + 音量摇杆，共 3 个输入位 | 盲操作任务与误触记录 |
| 32GB 已成常见卖点 | EVT-0 与目标产品使用同品牌/系列的 32GB 存储 | 装入测试内容、断网播放、校验拷贝 |
| App 管内容和升级 | EVT-0 使用目标 USB/卡完成相同生命周期，接口不绑具体 App | 安装、校验、回滚、重新上电 |
| 本地内容 + 在线扩展 | 已安装内容完全离线；联网只做可选同步 | 关闭 WiFi/拔网后完整回归 |
| 明确状态反馈 | 定义开机、读码、未绑定、播放、低电和错误灯语/音效 | 状态表逐项触发 |
| 角色化外观增强亲近感 | EVT-0 直接使用目标 CAD、握持区、镜头护口和声腔 | 握持、跌落、声学和镜头遮挡使用目标门 |

## 6. 到货观察与拆解记录

### 6.1 非破坏观察

每支样品使用同一张记录表：

1. 型号、SN 前缀、生产日期、固件/App 版本和包装清单。
2. 重量、外形包络、最粗握持直径、笔尖外径、充电口和按键行程。
3. 冷启动时间、点读确认方式、点到首音 P50/P95、连续点按与无效码反馈。
4. 断网后的点读、熏听、音量、暂停和重新上电行为。
5. 低电、充电、装包、升级失败和存储满的提示。
6. 码卡的印刷颜色、网点可见性、覆膜、曲面和不同距离/角度读码表现。

### 6.2 牺牲样机拆解

按层拍照并记录，不把丝印猜测成已确认料号：

- 笔尖镜头、补光、焦距限位和 OID 模组尺寸；
- OID 模组到主控的连接方式、电平和空闲/工作电流；
- 主控、存储、音频编解码/功放、扬声器与天线布局；
- 电芯容量、保护板、充电 IC、USB ESD 和热源位置；
- 按键、灯导光、跌落受力路径、螺钉柱和防夹手结构；
- 生产测试点、调试接口和可替换部件。

拆解输出只用于确定益米自己的规格、接口和可靠性测试，不复制商业内容、密钥或专有点读包。

## 7. 用户提供的业余拆解资料

2026-07-26，用户提供了一段点读笔原理/拆解视频的自动转写，以及两张视频截图。截图分别是功能框图和光学头近红外分层示意，不是带料号、比例尺和测量数据的实物剖面，因此统一标为 `U`。

| 转写或示意内容 | 当前判断 | 可进入 EVT-0 的动作 | 暂不据此冻结 |
|----------------|----------|---------------------|--------------|
| `光电识别 -> CPU -> 存储器 -> 耳机/喇叭`，并有按键、电池和 USB | 与当前通用点读笔架构一致 | 保留 `OID -> 本地索引 -> 本地音频` 主链及完整电源/交互验收 | 具体芯片、总线、存储介质和功耗 |
| 光学头由成像器件、镜头和补光构成 | 方向合理，截图标注 `C-MOS` 和红外 LED，但不是实物确认 | 下单前索取传感器类型、补光光谱、滤光、工作距和曝光/解码资料 | CMOS 料号、中心波长、视场、点径和分辨率 |
| 点码层吸收红外，普通 CMYK 图文层让红外穿透 | 可作为印刷分层工作假设；实际取决于颜料、碳黑、纸张、RIP 和覆膜 | 增加 K/CMYK/空白/哑膜/亮膜对照页及批次读码测试 | “普通 K 墨必然可用”或所有 CMYK 墨都近红外透明 |
| 微点叠印在图文之上，肉眼不显著影响画面 | 定性描述合理 | 实测目标印刷的可见度、套准、读码率和插画干扰 | “隐形”、最小面积、DPI 和码密度数值 |
| 不同品牌/代际存在兼容边界 | 方向上符合专有码制、码段、内容映射和授权分裂的市场现象 | 坚持目标 OID 码空间、生成工具和长期授权随模组一起验收 | “二代/三代”是全行业统一标准或具体品牌兼容结论 |
| “OID 编码 OLED”“隐形马”“自驾以外”等词 | 属于自动转写错字；分别按 `OID`、隐形码、自家以外理解，品牌名也需回看原视频 | 归一术语后再提取技术结论 | 原转写逐字准确性和转写中的具体品牌列表 |

该资料提高了“必须同时验收光头与印刷体系”的优先级，但不改变真实 OID、同版目标主板和同一 BOM revision 的主路线。

用户随后提供的整机拆板照片，以及组创微电子公开方案和“第四代 OID”搜索复核，单独记录于 [OID 主板与代际复核](./oid-board-generation-survey-2026.md)。主路线因此调整为：先单买近期一体主板/OID 套件，整板失格后再进入同版自研主板分支。
