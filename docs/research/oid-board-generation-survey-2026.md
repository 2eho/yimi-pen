# OID 点读笔主板与“第四代”口径复核

> 复核日期：2026-07-26
> 目标：寻找可单买、仍在供货、可进入 Gen1 EVT-0 的近期一体主板/OID 套件，并核实“第四代 OID”是否有统一技术定义。
> 结论：本轮公开资料未找到行业统一的“第四代 OID”标准或原厂定义；代际必须落到主板号、光头料号、码制/码空间、固件、印刷工具和量产日期。

## 1. 用户主板拆解照片

用户提供的照片只展示一台未标明 SKU、批次和固件版本的拆机内部，按 `U/V` 资料使用。

### 1.1 可直接观察

- 一块异形刚性主板贯穿笔尖、握持区和头部；握柄段细长，头部明显加宽并绕开扬声器/电池/结构空间；
- 主板中部有内部 microSD/TF 卡座；
- 外壳可见三个纵向正面按键帽，另有一个边缘开关类器件；
- 扬声器、电芯和笔尖光学头为独立机械件，通过线束、排线或连接器接入主板；
- 扬声器有独立圆形声腔和泡棉密封，PCB、电池、扬声器与光头均由壳体筋位/柱位约束。

### 1.2 尚待补证

- 主控/OID 解码/存储/音频/充电器件型号、PCB 层数和生产年份；
- microSD 容量和文件系统；电芯容量、保护、NTC 和充电拓扑；
- 扬声器阻抗、功率、灵敏度；光头通信、波长、镜头和工作距；
- 头部 U/C 形铜线或走线是否属于天线；照片不足以作此判断；
- 该板是否代表当前在售或“第四代”产品。

### 1.3 对 EVT-0 的直接影响

1. 目标板宽限制只约束握柄段；头部 PCB 可随电芯、扬声器、声腔、天线和壳柱形成异形加宽区。
2. 优先采购一块功能完整的近期一体主板，而不是先用矩形开发板拼接。
3. PCB outline、器件高度图、壳体 CAD、声腔、电芯膨胀空间和光轴必须同步冻结。
4. 三个正面键可作为当前基线，边缘开关功能保持 `TBD`，到货后再决定目标总键数。
5. 拆解样机需补拍主板正反面垂直高清图、毫米尺、全部 IC 丝印、电池/扬声器标签、OID 光头六面和连接器针数。

## 2. 组创微电子公开方案页

用户提供的 [点读笔方案开发](https://www.ztrontech.com/solutions/1.html) 是深圳市组创微电子有限公司的官方方案页。页面图片路径显示资源上传于 `2023-07-04`，可证明该公司公开过以下方案描述，但不代表 2026 年最新板卡。

### 2.1 页面明确列出的 PCBA

| 项 | 页面描述 | 采用边界 |
|----|----------|----------|
| 主控 | `ZC3205L` | 仅作为该页面方案身份，不直接认定仍在产 |
| 存储 | `128M-16G NAND Flash`、`128M-16G SD/TF` | 与板载/TF 内容架构方向一致，容量口径需核对 bit/byte 与当前料号 |
| 光头 | `95500 三代二合一笔头`、`Sonix 3代笔头` | 证明页面主规格写“三代”；需取得完整 MPN/revision |
| 接口/保护 | `USB 2.0 High Speed`、ESD 元件 | 需用实板和原理图确认具体实现 |
| PCB | 4 层板 | 只绑定该页面方案，不推广为所有点读笔事实 |

同一页面功能段又写“第二代加密型 OID 笔头”，与“三代”规格段冲突。该页适合进入候选池，但需先澄清板号、笔头号和正文版本。

### 2.3 春苗第二方案商入口

[春苗官方点读笔技术方案](https://www.szdianjiao.com/articles/readpen.html) 公开描述 PCBA
服务、4–32GB 本地存储、SDK、OID 桌面制作工具以及 MP3/WAV 支持，可作为与组创
使用同一问卷的第二家完整方案询证入口。页面未给出主板/光头准确 MPN、revision、
固件、接口、工具版本、离线许可和当前同版供货，因此在
[`board-evidence-matrix.csv`](../../hardware/evt0/board-evidence-matrix.csv) 中保持
`REF-CHUNMIAO-LOCAL / REFERENCE_ONLY`。

### 2.2 官方技术对比页

[蓝牙 Wifi 点读笔技术对比](https://www.ztrontech.com/educational1/119.html) 列出：

| 页面档位 | 页面架构 |
|----------|----------|
| 高端 | `SN95500 + ZC3205L + SPI Flash/NAND Flash + TF` |
| 中端 | `Sonix 3代笔头 + ZC95303 + SPI + 双 TF` |
| 低端 | `2000码笔头 + ZC7648 + SPI Flash/SPI NAND` |
| 智能 | `SN95500 + WiFi SoC/蓝牙 SoC` |

[智能 WIFI 点读笔方案](https://www.ztrontech.com/educational1/118.html) 把联网产品称为“第二代智能蓝牙/WiFi 点读笔”。这说明公开页面里的“代”至少同时用于笔头代际、加密口径和联网产品代际，不能横向等同。

## 3. “第四代 OID”搜索结果

本轮执行了精确词与组合词检索，并扫描组创官网 sitemap 中 `solutions`/`educational` 范围：

- 精确词：`第四代 OID`、`四代 OID`、`四代笔头`、`OID4.0`；
- 组合词：点读笔、主板、方案、笔头、PCBA；
- 组创官网公开范围未命中“第四代/四代”原始定义；
- 搜索结果主要是二手原理文章、旧 PCBA 图片或电商入口，未形成可核验的第四代主板 MPN/数据手册；
- 1688 搜索页要求登录/验证，公开页面未取得可引用的精确商品证据。

因此，本轮结论是：**“第四代 OID”属于待供应方解释的销售/产品口径，不是当前可直接写入 BOM 的技术规格。**

### 3.1 松翰当前官方目录交叉核对（2026-08-03）

松翰 OID 官方 API 当前列出：

- Decoder：`SN95310 / SN95350 / SN95360`；
- Sensor Module：8 个家族，其中包括 `SNM9S5X30BC2100A`；
- `SNM9S5x30(B)C2100A_DS_V1.1` 进一步列出
  `SNM9S5430BC2100A / SNM9S5630BC2100A`；
- 官方 2-wire V1.3 手册覆盖 `SNM9S53xx/54xx` 模组接口。

API 分类更新时间为 2026-03-31；响应请求体、字节数和 SHA-256 已进入
[`evidence-sources.json`](../../hardware/evt0/evidence-sources.json) 的
`SRC-OID-004…010`。目录出现与 `cStatus=1` 只证明官网当前分类，不证明库存、MOQ、
交期、`HEAD_REV` 或完整 PCBA 组合。

组创页面使用的 `SN95500/95500` 在本轮松翰当前 Decoder/Sensor Module 列表中未检得。
这里只记录“缺少当前目录交叉确认”，继续向方案商询问完整 MPN 和当前替代关系；
不从一次目录缺失推导生命周期结论。

## 4. 四代候选入场表

任何标注“四代/第四代/OID4.0”的主板或光头，先填写以下表格；缺精确证据时保持 `BLOCKED`。

| 字段 | 必须证据 |
|------|----------|
| `BOARD_MPN / PCB_REV` | 主板正反面、板号、revision、尺寸和当前生产日期/批次 |
| `HEAD_MPN / HEAD_REV` | 光头六面、排线/连接器、镜头、补光、解码边界和机械图 |
| “四代”比较基线 | 明确相对哪一代、哪一料号提升；列出码点、工作距、角度、时延、功耗或码空间差异 |
| 码制/码空间 | 名称、版本、原始位宽、总量、客户可分配段和冲突管理 |
| 生成与印刷 | 码生成工具版本、油墨/分色/RIP/纸张/覆膜参数和两个独立印刷批次 |
| 主板功能 | 存储、音频格式/输出、USB、按键、灯、电池/充电、无线和日志 |
| 固件/SDK | 版本、构建/升级/回滚、错误码、离线授权和维护周期 |
| 当前性 | 2024-2026 生产/销售/PCN 证据，样品与以后批量同版承诺 |
| EVT-0 证据 | 两只同版光头 x 两批印刷、首音、离线、负样、跌落后复测 |

## 5. 对组创的单件询问清单

对该公司只需先询问单件工程样品，不进入批量议价：

1. 目前实际在产的点读笔主板型号、PCB revision、生产日期和正反面高清图；
2. `ZC3205L / ZC95303 / SN95500 / 95500` 中哪些仍在产，当前推荐替代料是什么；
3. 页面“三代二合一”“Sonix 3代”“第二代加密型”分别对应的完整光头 MPN/revision；
4. 是否存在其内部所称“四代”光头/主板；若有，提供相对上一代的量化差异和数据手册；
5. 两套同板号主板 + 两只同版光头 + 24 码卡 + 码生成/印刷工具能否单买；
6. USB、TF/NAND、音频、按键、充电、无线、日志和装包工具的当前资料；
7. 离线读码/播放、码空间与长期使用条款；
8. 样品与以后批量是否保持同一板号/光头/固件/码制 revision。

在这些问题回填前，组创方案在 [BOM 锁定台账](../../hardware/evt0/bom-lock.csv) 中保持候选状态，不把 `ZC3205L`、`SN95500` 或“三代/四代”字样直接冻结为目标。
