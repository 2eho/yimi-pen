> RFQ 版本：v0.3
> 日期：2026-08-03
> 状态：当前只发送 `M01-M08` 预询证；同版批量采购、授权和第二来源条款在 EVT-0 实物证据通过后启用。

## 1. 项目摘要

益米 Gen1 是一支面向儿童绘本和家庭 DIY 内容的无屏点读笔。当前处于 EVT-0
证据冻结与候选筛选阶段，候选样机和后续批量方案必须实现：

```text
OID -> 本地索引 -> 本地缓存音频 -> 扬声器
```

关键目标：

- 已缓存内容点到首音 P95 `<200ms`；
- 已安装内容在无网络、无账号时可永久播放；
- 方案商提供可量产的码空间、码生成/印刷工具和书面授权边界；
- OID 事件通过 `BOARD_TARGET` 的供应商 API、板载日志或稳定帧协议进入窄适配边界；只有自研分支才预设独立 UART/SPI 驱动；
- 候选 EVT-0 与后续批量产品引用同一 `BOARD_TARGET + OID_TARGET_HEAD`、BOM、固件和验收；自研分支另保持同一 PCB。替料或改架构必须建立新 revision 并重跑受影响门。

预计阶段量：候选验证 2-10 套，工程批 30-50 台，首批试产 100-1,000 台。该数量是询价阶梯，不构成采购承诺。

### 1.1 原厂目录交叉核对（不指定供应商方案）

2026-08-03 复核的松翰官方 OID 目录把以下对象列为当前资料中的准确身份：

| 角色 | 官方目录/资料中的身份 | 询证用途 |
|---|---|---|
| OID Decoder | `SN95310 / SN95350 / SN95360` | 要求方案商写明完整解码器 MPN、SDK、工具链和与模组的验证组合 |
| OID Sensor Module 家族 | `SNM9S5X30BC2100A` | 要求继续落到具体变体、revision、连接器、镜头/补光和机械资料 |
| 2100A 资料中的具体变体 | `SNM9S5430BC2100A / SNM9S5630BC2100A` | 首选 RFQ 核对项，不预先认定为可订购完整笔头 |
| 模组接口资料 | `SNM9S53xx/54xx 2-wire Interface Manual V1.3` | 核对供应商板卡实现、事件语义、电气时序和可观测测试点 |

来源与响应字节哈希见
[`evidence-sources.json`](../../hardware/evt0/evidence-sources.json) 的
`SRC-OID-004…010`。若候选使用其他原厂或其他组合，同样提交准确 MPN 与原厂资料；
若答复仍使用 `95500/SN95500/三代/四代` 等简称，需补充其当前完整 MPN、相对基线
和替代关系。当前官方目录中未检得 `SN95500` 只表示缺少本轮目录交叉确认，不据此
推断停产、兼容或替代状态。

上述身份只缩小询证歧义。完整 `BOARD_MPN / PCB_REV / HEAD_MPN / HEAD_REV /
FW_VERSION`、库存、同版供货和两套实物仍是付款门。

## 6. 样品验收

益米在收到完整交付包后执行统一 EVT-0 回归：

1. 两套同版一体主板/OID 套件分别覆盖全部 24 个有效码，合计完成 1,000 次标准点读；
2. 错码 `0/1,000`，空白误触发 `0/500`；
3. 合并本地音频链后点到首音 P95 `<200ms`；
4. 关闭网络、断开调试电脑后连续完成 100 次正确播放；
5. 缺文件、坏索引、拔卡和中断写入能给出明确错误并恢复；
6. 实测工作距、倾角、哑膜/亮膜、环境光和功耗风险矩阵；
7. 所有结果绑定主板 MPN/PCB revision、光头 revision、SDK/固件/码工具版本和码卡批次。

详见 [Gen1 EVT-0 单件目标样机](../hardware-gen1-p0.md)。供应商自己的测试报告不能代替该回归，但可帮助解释差异。
