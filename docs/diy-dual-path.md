# 实体 × 图书 双 DIY

## 一句话

**贴纸让现实可点，拍照让现实成书；笔只认开放包格式，不认大厂锁区库。**

## 用户故事

### 贴纸 · 香蕉夜话

1. 家长从益米贴纸册撕下 `YIMI-DIY-0A31`  
2. 贴在香蕉上  
3. 打开 App →「绑定物体」→ 拍香蕉（或手选「水果/香蕉」）  
4. AI 生成：  
   - 3 条角色短句（`random_one`）  
   - 1 段 30 秒小故事（`story` / `queue`）  
   - 可选：卡通香蕉贴纸图（分享用）  
5. 家长点「收听预览」→「写入笔/家庭库」  
6. 孩子用笔点香蕉 → 当场播放  

### 绘本 · 从冰箱到故事书

1. 拍香蕉（或孩子的蜡笔画）  
2. AI **卡通风格化** 出图  
3. 选模板：单页卡 / 8 页小书  
4. AI 写旁白 + TTS  
5. 导出 `book.json` + 图片 + 音频（标准 Pack）  
6. 家用打印机或打印店出力  
7. 可选：页角印 OID 或贴透明点读贴  
8. 笔按页点读；包也可分享到社区（需声明原创/授权）

## 为什么这比「兼容大厂书」强

| | 盗/兼容商业包 | 双 DIY |
|--|---------------|--------|
| 法律 | 高风险 | 用户自有内容 + 公版 |
| 技术 | 对抗加密、无文档 | 自有格式完全可控 |
| 品牌 | 山寨感、易社死 | 创作工具、教育向 |
| 差异化 | 永远跟跑 | **万物可点** 叙事成立 |
| 成本 | 法务与下架 | 算力与审核 |

## AI 模块边界（务实）

| 模块 | 输入 | 输出 | 注意 |
|------|------|------|------|
| 物体理解 | 照片 | 标签、短描述 | 可离线小模型 + 云端增强 |
| 故事生成 | 标签+年龄+语气 | transcript 文本 | 安全词表、家长确认 |
| TTS | 文本 | mp3/wav clip | 可换引擎；缓存 |
| 风格化 | 照片 | 卡通页图 | 打印出血/DPI 模板 |
| 排版 | 图+文 | 多页 PDF + book.json | 固定页尺寸 |

**原则**：AI 是 **作者助手**，不是「自动盗版机」。默认生成物版权归用户；上传社区必须勾选权利声明。

## 贴纸硬件策略

| 类型 | 说明 |
|------|------|
| 空白 OID 贴 | 出厂烧唯一码，App 绑定语义 |
| 打印页角码 | 绘本 DIY 用，模板预留码位 |
| 无码坐标页 | 仅平板/扫描笔方案（后期） |

一期只做 **空白 OID 贴 + App 绑定**，最便宜、最好讲故事。

## 与 IoT（方案 B）的关系

- DIY 是主食，IoT 是调料。  
- 例：点「晚安香蕉」故事结束 → MQTT 通知关灯（用户自建自动化）。  
- 不宣称官方小爱技能；可用开放网关/HA。  

## MVP 切片（建议实现顺序）

1. **绑定**：OID + 手动命名 + 文案台词 — **已实现**（见 [diy-bind.md](./diy-bind.md)，模拟器 `bind`/`say`/`tap`）  
2. **本地录音**：写入 `content/audio/diy/` 替换 `diy:tts:`  
3. **TTS 故事**：文本模板 + 一种 TTS → 自动 clips  
4. **拍照标签**：云端/本地视觉 → 填模板  
5. **卡通页 + 打印模板** PDF  
6. **一键导出 Pack** 进 `content/packs`  
7. 可选 MQTT 事件  

## 社区规则（重复强调）

1. 禁止商业点读包传播  
2. DIY 分享须无侵权素材  
3. 公版名著需标注版本与来源  
4. 违规包下架且可封禁上传者
