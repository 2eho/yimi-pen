# 益米 · 商业边界与可持续定稿

> 状态：**理论定稿 v0.1**（专题 3/3）  
> 上级文档：[theory.md](./theory.md)  
> 范围：开源与收费边界、谁付钱、耗材、云服务、社区激励。  
> 不范围：具体定价、股权融资条款。

---

## 0. 一句话

**引擎与格式永远开源可自建；官方可卖「省事的实物与可选云」——花钱买便利，不花钱买锁区内容。禁止靠盗版库或假冒米家官方变现。**

---

## 1. 为什么开源还要谈商业

| 现实 | 回应 |
|------|------|
| 笔、贴、认证要成本 | 需要可持续收入或赞助 |
| 社区怕被「开源换皮收割」 | 必须划清 forever-free 边界 |
| 纯捐赠难撑供应链 | 耗材与硬件是诚实商业路径 |
| 云复刻有算力成本 | 可选订阅，默认本地可用 |

**商业不得反向修改 theory：**  
不得为了赚钱恢复「商业点读包盗传」或「冒充米家官方」。

---

## 2. 分层：永远免费 vs 可收费

### 2.1 Forever Free（社区承诺级）

| 资产 | 说明 |
|------|------|
| 点读引擎、协议、模拟器、校验工具 | Apache-2.0 |
| Pack 格式规范 | 公开，可独立实现 |
| 自建家庭库 / 自建 Hub | 允许，无强制官方服务器 |
| 本地 DIY 绑定 + 文案 | 不强制付费 |
| 官方样例包 | 保持可复制许可 |
| 「米家友好」桥接文档与参考实现 | 开源；非官方认证费 |

### 2.2 可收费（诚实便利）

| 项目 | 正当性 |
|------|--------|
| **益米笔硬件** | 制造、认证、质保 |
| **官方空白 OID 贴纸** | 印刷、码段、材料合规（含食品级 SKU） |
| **官方打印绘本纸模/套装** | 纸张、套准、省事 |
| **可选云音色复刻** | GPU/API 成本；须可删可停 |
| **可选云 AI 故事/识图** | 调用成本；本地模板须仍可用 |
| **延保 / 企业/园所部署** | 服务而非锁内容 |
| **周边** | 无强制 |

### 2.3 明确不卖 / 不做

| 禁止商业模式 | 原因 |
|--------------|------|
| 加密盗版书库订阅 | 违法 + 社死 |
| 「解锁全部大厂点读书」 | 同上 |
| 强制订阅才能点自己绑的贴纸 | 违背 DIY 主权 |
| 卖「官方小米授权」旗号（无授权时） | 商标与欺诈风险 |
| 出卖儿童点读数据给广告商 | 伦理与合规 |
| 开源核心闭源化换皮（对已 Apache 代码） | 许可与社区信任 |

## 3. 推荐默认商业叙事（对外）

> 益米开源点读引擎与格式，谁都可以做笔和包。  
> 我们卖的是：**好用的笔、合规的贴纸、省事的云选项**。  
> 你的故事与爸妈的声音，默认是你的，不是月费墙后的出租物。

## 4. 硬件商业

| 要点 | 说明 |
|------|------|
| 开源硬件深度 | 鼓励原理图/结构开源；Gen1 可后置，但不以闭源硬件阻止第三方笔读益米 Pack |
| 兼容笔 | 第三方笔只要协议与格式正确即可；官方不保证全兼容，但**不刻意加密锁死** |
| 认证成本 | 售价须覆盖 3C/玩具等（区域依赖） |
| 教育渠道 | 园所版本可加管理功能，不卖侵权内容 |

---

## 5. 耗材：空白贴纸（关键路径）

| 点 | 说明 |
|----|------|
| 为何关键 | 万物可点的物理入口；复购自然 |
| 官方贴 | 码段清晰、材料分档、识别率质检 |
| 第三方贴 | 允许；工具可生成自印码（体验与安全自负） |
| 与开源关系 | 码规范公开；不靠秘密算法绑死只买官方贴（可用校验增值，不作唯一） |

**迁移绑定**（硬件专题）：换贴不丢内容 → 降低耗材焦虑，反而利于长期信任。

---

## 6. 云与 AI 商业

| 规则 | 说明 |
|------|------|
| 本地路径可用 | 无云也能 bind + 录音/本地 TTS（能力可较弱） |
| 云是加速档 | 更好复刻、更快识图 |
| 计费透明 | 按次/订阅说清；儿童账户默认限制 |
| 停订 | 已缓存音频仍可点；仅失去新合成 |
| 数据 | 见 safety；不作广告画像 |

---

## 7. 社区 Pack 与激励

| 模式 | 态度 |
|------|------|
| 自愿 CC 分享 | 主路径 |
| 打赏/爱发电链到作者主页 | 允许，平台可抽成须公开 |
| 官方精选实体印刷 | 与作者分润合同另议 |
| 付费加密包 | **不鼓励**进主 Hub；若作者自建商店，须自有版权且不走盗版 |
| 贡献代码 | 荣誉、周边、可选资助 |

冷启动：官方免费优质样例 + DIY 工具省力 > 空喊「生态」。

## 8. 商标与品牌边界（钱与法）

| 项 | 态度 |
|----|------|
| 「益米」「Yimi Pen」 | 应尽早检索与申请商标（行动项） |
| 「米家友好」 | 描述性、加「非官方」；不作主标题品牌 |
| 视觉 | 避免模仿小米/米家 VI |
| 加盟商 | 禁止第三方打「小米点读笔」卖益米 |

---

## 9. 开源治理与钱

| 项 | 态度 |
|----|------|
| 项目资金 | 可接受赞助、硬件利润反哺、基金会（远期） |
| CLA | 可选；无 CLA 时靠 DCO/许可头 |
| 核心插件闭源 | 允许**周边服务**闭源，核心引擎保持 Apache |
| 贡献者商业 fork | 允许，须遵守许可与商标 |

---

## 10. 定价哲学（不写数字）

1. **硬件：** 可感知品质与安全认证，不走最廉价毒材料。  
2. **贴纸：** 亲民耗材，避免「卖笔送贴、贴比笔贵」的恶意模型。  
3. **云：** 明显可选；年费感不应超过「便利」心理账户。  
4. **教育版：** 管理功能加价，不锁格式。  

---

## 11. 竞争与护城河（商业视角）

| 若竞品… | 益米靠 |
|---------|--------|
| 也做贴纸 DIY | 开放格式 + 社区 + 亲情音色默认本地 |
| 锁生态 | 第三方笔与自建 Hub |
| 低价砸硬件 | 耗材与云 + 品牌信任（安全、合规） |
| 告侵权（若我方干净） | 法务准备与内容红线 |

护城河写在 theory：工具链与信任，不是独家盗版库。

## 12. 决策摘要

| ID | 决策 |
|----|------|
| B1 | 引擎/格式/自建 forever free |
| B2 | 可售：笔、官方贴、纸模、可选云、服务 |
| B3 | 不售：盗版库、假官方、强制订阅锁 DIY |
| B4 | 停云不删已缓存点读 |
| B5 | 耗材是主商业路径之一，规范公开 |
| B6 | 商标与「非米家官方」表述强制 |
| B7 | 社区激励以自愿与透明分润为主 |
| B8 | 商业不得推翻 safety/theory 红线 |
