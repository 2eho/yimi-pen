# 亲情音色（Voice Profile）

## 你要的能力（用白话）

1. **先录几段**：爸爸/妈妈对着 App 读几句话（录入）  
2. **存成「音色档案」**：系统记住「妈的声音长什么样」  
3. **以后只打字**：例如香蕉贴纸绑定文案「我是香蕉～」  
4. **用爸妈的声音念出来**：孩子点贴纸，听到的是熟悉的人声，不是机械女声  

这和「登录用的声纹解锁」不是一回事，也和「识别现在是谁在说话」无关。

| 概念 | 干什么 | 益米用不用 |
|------|--------|------------|
| **亲情音色 / 声音复刻** | 用少量录音，让 TTS **用这个人的音色读任意新句子** | **要，核心体验** |
| **说话人嵌入 / 声纹特征** | 技术上往往是复刻流水线的中间特征 | 实现细节，可有 |
| **声纹门禁** | 验证是不是机主才能开机 | **当前不做** |
| **录音当固定 mp3** | 录一句只能播这一句，不能改字 | 可作兜底，表达力弱 |

产品一句话：

> **录的是「音色」，用的是「打字 → 按这个音色朗读」。**

---

## 用户流程

```
创建档案「妈妈」
  → 同意授权（consent）
  → 跟读 5～10 句（enrollment samples）
  → 状态 ready
  →（可选）云端/本地 build 音色模型
  → DIY：bind / AI 故事 指定 voiceProfileId=mom
  → 点贴纸 → TTS(文本, 妈妈音色) → 播放
```

香蕉例子：

1. 录入妈妈音色一次  
2. `bind YIMI-DIY-BANANA 香蕉 我是一根香香的香蕉` + `--voice mom`  
3. 以后改文案、AI 新故事，**不用重新录音**，仍是妈妈声  

---

## 为什么对益米重要

| 价值 | 说明 |
|------|------|
| 情感 | 孩子对父母声音更安心、更好玩 |
| DIY 闭环 | 打字/AI 生成海量句子，不会每句都真人录 |
| 差异化 | 大厂书库难做「你家专属声音」 |
| 与双 DIY 一致 | 贴纸/绘本旁白都可指定家庭音色 |

---

## 技术分层（务实）

```
[录入]  麦克风 → wav/mp3 samples
   ↓
[表征]  speaker embedding / 声纹特征（可选中间步）
   ↓
[复刻 TTS]  文本 + profile → 音频
   ↓
[点读]  与现有 Clip 一样播放（可缓存成文件，离线点读）
```

实现路线（由易到难）：

1. **MVP 数据层**（已做骨架）：`VoiceProfile` + samples 列表 + consent  
2. **假朗读**：仍用 `diy:tts:` 打印文案，但标记 `voiceProfileId`  
3. **真 TTS**：接入可指定 speaker 的服务（开源/云）  
4. **真复刻**：Few-shot voice clone（本地或云 API）  
5. **缓存**：生成后写入 `content/audio/diy/...mp3`，笔端离线播  

---

## 隐私与合规（必做）

- **明示同意**：录入前勾选「仅用于本机/家庭点读朗读」  
- **最小采集**：只存 enrollment 句，不常开麦克风  
- **可删除**：一键删档案与全部样本  
- **不上传默认**：默认本地；云复刻需再次授权  
- **儿童**：孩子声音录入需监护人同意  
- **不做**：用声纹做广告追踪、陌生人识别、未授权模仿公众人物  

社区规则建议补充：禁止上传他人声音档案到公开 Pack（除非权利人授权）。

## 数据位置

```
content/diy/voices.json          # 档案索引
content/audio/voices/<id>/*.wav  # 录入样本（真文件后）
```

类型：`@yimi-pen/core` → `VoiceProfile` / `VoiceProfileStore`  
模拟器命令见 `docs/diy-bind.md` 与 sim `voice` 系列。

---

## 和「录音绑定贴纸」的关系

| 方式 | 适合 |
|------|------|
| **固定录音 clip** | 一句永不改的话、拟声、儿歌片段 |
| **亲情音色 + 打字/AI** | 句子常变、故事生成、大量贴纸文案 |

两者并存：特殊音效用固定 mp3；旁白/角色台词用妈妈声 TTS。
